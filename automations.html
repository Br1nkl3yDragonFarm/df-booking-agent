When a show is booked, a deposit is paid or a fan signs up, the tool can tell n8n, a workflow tool, which then does the follow-on chores for you: post the show to Discord or social media, add a row to a Google Sheet, text you, start a release checklist. You build those steps in n8n by dragging blocks together; nothing here changes how the tool works on its own.

What gets sent

Each button sends a made-up example of that event, marked "sample": true, so you can build and try a workflow without waiting for a real one.

    Set it up

    1. Get n8n: n8n Cloud (paid, nothing to run) or the free self-hosted version on a small server (hosting guide).
    2. In n8n: Workflows → Import from file and pick n8n/dragon-farm-events.json from this project. It starts with a Webhook block and splits each kind of event to its own path.
    3. Open the Webhook block, copy its Production URL, then turn the workflow on (Publish, or the Active switch in older n8n).
    4. In Netlify: Site configuration → Environment variables, add N8N_WEBHOOK_URL with that URL. Optionally add N8N_WEBHOOK_SECRET (any long random text) and the same text as secret in the workflow's Settings step, so n8n ignores anything that didn't come from you. Redeploy.
    5. Come back here and press Send test on an event. It shows up under Executions in n8n.

    Discord and the Google Sheet log turn on by pasting their addresses into the workflow's Settings step: a Discord channel webhook as discordWebhook, the sheet's Apps Script web app URL as sheetsWebhook (README step 11 shows how to make it with n8n/google-sheets-log.gs), and a private ntfy topic as ntfyTopic for phone alerts on card payments and replies. Left empty, that step is skipped. Other steps are yours to add: Instagram or Facebook posts, a text message through Twilio, a Trello card, anything n8n connects to.
